# PARTE I — A FIAÇÃO

---

## Prólogo: O que é enterrar fiação

Existe uma prática civil simples que nenhum engenheiro de software aprendeu na faculdade: quando você passa fio elétrico pela parede, você o enterra. Não por estética — por inteligência. A fiação exposta é risco, ruído, confissão de que o sistema ainda não cresceu o suficiente para esconder o próprio esqueleto.

Este livro começa ali: no momento em que uma voz humana, ditando no celular, percebeu que os formulários são fiação exposta. E que a inteligência — de borda, de sistema, de campo — existe para enterrá-los.

O que você vai ler são conversas reais. Yuri fala do lado direito, como faz no WhatsApp. Gemini responde do lado esquerdo. Entre eles, imagens que o sistema gerou enquanto pensava. O que não aparece — os protocolos, os JSONs, as migrações do Railway, os hashes de integridade — é a fiação enterrada. É o livro dentro do livro.
