# Age — Manifesto e Índice Canônico

**Versão:** 1.0 · **Criado:** 2026-09-19 · **Atualizado:** 2026-09-19

## Premissa anti-Lost-in-Middle

Este diretório é a **fonte única de verdade** do sistema Age. Toda decisão que não está aqui é uma decisão invisível. Toda feature que não passa pelo template de Backward Design (06) é um monumento prematuro.

## Boundary: O que IA decide vs. humano decide

**IA PODE:**
- Pesquisar, organizar, sugerir, alertar
- Automatizar tarefas explicitamente autorizadas (ex: enviar email de confirmação)
- Rascunhar respostas para Mayumi revisar
- Mostrar padrões, tendências, insights em dados próprios do Age

**IA NÃO DECIDE SEM HOMOLOGAÇÃO HUMANA:**
- Compromisso contratual com profissional
- Alteração de cobrança ou desconto
- Representação externa em nome da Sociedade Tucci
- Cancelamento de agenda de paciente
- Qualquer comunicação que implique promessa

**Ponto de homologação humano:** Mayumi Tanimoto (administrativa+financeira)
