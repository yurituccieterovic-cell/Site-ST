CENTER: hexapod robot silhouette at the split line, half-organic/half-circuit,

PALETTE: #0D1B2A bg, #00B4D8 cyan, #2DC653 green, #F0A500 amber.

## Instrucoes Canva

```
1. Canva > Criar design > A4 (210 x 297mm) ou Instagram Post (1:1)
2. Clique "+ Adicionar" > Magic Media > colar o prompt acima
3. Exportar: PNG 300dpi para PDF, JPG para email
4. Salvar em: /root/Site-ST/aliancapanorama-src/livro-imagens/
   - capa.png
   - cap-1-1.png
   - cap-1-2.png
   - cap-1-3.png
   - cap-1-4.png
   - cap-1-5.png
5. Para PDF v4 com imagens reais: adicionar Pillow ao sistema e
   usar pdf.image(path, x, y, w) no lugar do placeholder
```
