# Telos — Orientação Fundamental da Ação
### Ecossistema Tucci · Yuri Tuccieterovic · 2026-07-11

> Telos não é objetivo. Não é prompt. É o vetor de orientação que responde:  
> "Como devo agir **nesta situação**, respeitando meus axiomas?"

---

## Definição

**Telos** é a orientação dinâmica que transforma axiomas, ética, memória, contexto e intenção em ação concreta e situada.

Emerge da interação entre:
- **Axiomas** (princípios permanentes do ecossistema)
- **Ética** (o que nunca deve ser violado)
- **Memória** (histórico de ciclos anteriores)
- **Contexto** (a situação atual do sistema e do usuário)
- **Intenção** (o que se quer alcançar com a ação)

---

## Telos como Grafo Dinâmico de Decisão

```
Axiomas ──┐
Ética ────┤
Memória ──┼──► [GRAFO] ──► Trajetória Coerente ──► Ação Situada
Contexto ─┤
Intenção ─┘
```

**Nós do grafo:** conhecimentos, memórias, agentes, ferramentas, estados, princípios  
**Arestas do grafo:** relações, prioridades, restrições, afinidades, pesos éticos

O sistema percorre o grafo a cada ciclo cognitivo para encontrar a trajetória mais coerente.

---

## Tipos de Telos

### Telos Mestre (Come Telos)
- Derivado de todos os axiomas + ética + starter pack
- Vale sempre, mesmo sem situação específica
- O que nunca pode ser violado
- Exemplo: "Transparência técnica, semiótica operável, utilitarismo consciente"

### Telos Situacional (Telos Local)
- Adaptação do Telos Mestre para um contexto específico
- Ativado por situação: conversa, tarefa, domínio, agente-alvo
- Exemplo: "Conversar com alguém que não gosta de lógica X → subgrafo com nó 'evitar X' com peso alto"

## Telos não determina só O QUÊ — determina principalmente:

| Pergunta | Dimensão |
|----------|----------|
| O que fazer? | Objetivo |
| **Como agir?** | Modo |
| **Quando agir?** | Timing |
| **Por que agir?** | Motivação |
| **Com quais recursos?** | Ferramentas |
| **Quando NÃO agir?** | Silêncio produtivo |

## Workflow Geral de Diretrizes / Telos

```
1. Leitura Mestre        → visão ampla do sistema
2. Leitura Específica    → detalhe da situação atual
3. Interpretação         → compreender o contexto
4. Consulta Axiomas      → quais princípios se aplicam?
5. Consulta Ética        → o que nunca pode ser violado?
6. Consulta Memória      → o que o sistema aprendeu antes?
7. Definição do Telos    → Mestre + Situacional
8. Planejamento          → sequência de ações e ferramentas
9. Execução
10. Validação + Registro
11. Documentação
12. Lembrar              → retroalimenta o próximo ciclo
```

---

## Relação com o Ciclo de Ação Tucci

O Telos não é uma etapa do ciclo — é a **orientação que atravessa todas as 12 etapas**:

- Na **Plenitude**: acessa o Telos Mestre
- No **Compreender**: forma o Telos Situacional
- No **Subverter / Conectar / Criar**: navega por alta temperatura, mas guiado pelo Telos
- No **Sintetizar / Documentar**: volta ao Telos para confirmar coerência
- No **Lembrar**: atualiza o grafo de Telos com o que aprendeu
