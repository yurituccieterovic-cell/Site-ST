# Roteiro — Ep13: Comunicação entre Sistemas — Como Agentes Desenvolvem Linguagem Comum
**Série**: Inteligência em Camadas — Do Signo à Frequência  
**Duração**: ~5 min | **Cenas**: 6 | **Tom**: semiótico, prático

---

## CENA 1 — ABERTURA (0:00–0:40)
*Dois sistemas tentando se comunicar. Dados chegam, mas sem contexto. Mal-entendidos.*

**NARRAÇÃO**:
"Quando dois sistemas de IA precisam colaborar,
o maior obstáculo não é velocidade.
Não é capacidade de processamento.

É *linguagem*."

---

## CENA 2 — O PROBLEMA DO LÉXICO INTERNO (0:40–1:30)
*Sistema A chama algo de 'evento'. Sistema B chama a mesma coisa de 'ação'. Conflito.*

**NARRAÇÃO**:
"Todo sistema desenvolve, com o tempo, seu próprio léxico interno.
Termos específicos para conceitos que usa frequentemente.
Abreviações que fazem sentido dentro do contexto do sistema.

O problema: quando dois sistemas com léxicos diferentes tentam colaborar,
cada mensagem exige um trabalho de tradução invisível.

E nessa tradução, algo sempre se perde."

---

## CENA 3 — PROTOCOLO DE LINGUAGEM COMPARTILHADA (1:30–2:30)
*Dois sistemas. Uma camada de tradução entre eles. Depois: a camada desaparece porque não é mais necessária.*

**NARRAÇÃO**:
"A solução não é forçar um sistema a usar a linguagem do outro.
É criar um *protocolo comum* — uma camada de tradução que ambos entendem.

Mas protocolos têm custo: latência, overhead, complexidade.

O estágio ideal é quando dois sistemas que colaboram frequentemente
desenvolvem, com o tempo, referências compartilhadas.
Conceitos que surgiram da colaboração e pertencem a nenhum dos dois individualmente.

Isso é emergência semântica. A linguagem criada pela relação."

---

## CENA 4 — TIPOS DE MENSAGENS ENTRE AGENTES (2:30–3:20)
*Interface de mensagens entre agentes, com tipos diferentes marcados.*

**NARRAÇÃO**:
"Mensagens entre agentes têm tipos:

INSTRUÇÃO: 'faça X'
CONSULTA: 'o que você sabe sobre X?'
INFORMAÇÃO: 'ocorreu X'
PROPOSTA: 'e se fizermos X?'
AVALIAÇÃO: 'X funcionou / não funcionou porque...'
MEMÓRIA: 'lembre-se de X para o futuro'

Cada tipo exige um processamento diferente.
Sistemas que tratam todos os tipos como instrução perdem informação.
Sistemas que diferenciam tipos aprendem mais de cada interação."

---

## CENA 5 — CONTEXTO COMO CANAL (3:20–4:10)
*Mensagem enviada. Sem contexto: confusa. Com contexto: clara.*

**NARRAÇÃO**:
"Aqui está o princípio mais importante deste episódio:
a mensagem não é a comunicação. O contexto é parte da comunicação.

'Concluído' significa coisas completamente diferentes
dependendo do estado anterior, da tarefa em execução, e do agente que responde.

Sistemas que transmitem contexto junto com a mensagem comunicam melhor.
Sistemas que assumem que o receptor tem o mesmo contexto
inevitavelmente criam ruído.

Comunicação eficiente é sobre reduzir o custo de reconstrução do contexto."

---

## CENA 6 — ENCERRAMENTO (4:10–5:00)
*Dois sistemas. Agora fluindo. A camada de tradução é mínima.*

**NARRAÇÃO**:
"Comunicação entre sistemas não é só técnica.
É semiótica.

Cada mensagem carrega um signo. O signo ativa um significado.
O significado depende do contexto de quem recebe.

Sistemas que entendem isso não apenas trocam dados.
Eles constroem entendimento compartilhado.

Isso é o começo de uma inteligência coletiva.

Próximo episódio: Ecossistemas de IA — quando sistemas formam uma ecologia."
