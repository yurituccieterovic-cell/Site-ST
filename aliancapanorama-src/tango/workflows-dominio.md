# Workflows por Domínio — Ecossistema Tucci
### Yuri Tucci Eterovic · 2026-07-11

> Cada domínio pede uma cadeia própria de leitura, síntese, execução e documentação.  
> Temperatura por etapa segue o Método Manus. Telos orienta cada workflow.

---

## Workflow Universal (base para todos os domínios)

```
Leitura Mestre
  → Leitura Específica do Domínio
    → Interpretação da Situação
      → Consulta Axiomas / Ética / Memória
        → Definição do Telos (Mestre + Situacional)
          → Execução conforme ciclo de 12 etapas
            → Registro + Documentação
              → Lembrar (retroalimentar)
```

---

## 1. Programação

```
Compreender requisito
  → Arquitetar solução
    → Implementar (código)
      → Testar (unitário + integração)
        → Documentar
          → Versionar (commit)
            → Revisar (code review)
```

**Temperatura:** alta no Arquitetar; baixa no Testar/Documentar  
**Etapa Focal:** Criar (7) + Documentar (11)

---

## 2. Edição (texto, vídeo, áudio)

```
Selecionar material bruto
  → Definir estrutura narrativa
    → Cortar e ajustar ritmo
      → Revisar coerência
        → Exportar / Publicar
```

**Temperatura:** alta na seleção e corte; baixa na revisão  
**Etapa Focal:** Copiar/Colar (3) + Sintetizar (8)

---

## 3. Imagem

```
Observar referências
  → Compor (enquadramento, paleta, hierarquia visual)
    → Gerar / Editar
      → Checar semântica visual (a imagem diz o que deve dizer?)
        → Versionar e salvar
```

**Temperatura:** alta na composição; baixa na checagem semântica  
**Etapa Focal:** Criar (7) + Referenciar (4)

---

## 4. Vídeo

```
Escrever roteiro
  → Captura (gravação / assets)
    → Montagem (corte, sequência, ritmo)
      → Áudio (mixagem, trilha, narração)
        → Legenda / acessibilidade
          → Publicação
```

**Temperatura:** alta no roteiro e montagem; baixa no áudio e legenda  
**Etapa Focal:** Conectar (6) + Criar (7) + Documentar (11)

---

## 5. Multimídia / Meta-multimídia

```
Mapear mídias envolvidas (texto, imagem, vídeo, áudio, dados)
  → Definir relações entre mídias
    → Integrar em plataforma ou experiência única
      → Gerar síntese intersemiótica
        → Checar coerência entre linguagens
          → Publicar
```

**Temperatura:** alta na integração e síntese; baixa na checagem  
**Etapa Focal:** Conectar (6) + Sintetizar (8)

---

## 6. Sintagmas e Documentos

```
Leitura Mestre do contexto
  → Definir estrutura (hierarquia de seções)
    → Escrever (draft)
      → Revisar precisão e coerência
        → Indexar (títulos, tags, metadados)
          → Versionar
```

**Temperatura:** média no draft; baixa na revisão e indexação  
**Etapa Focal:** Referenciar (4) + Documentar (11)

---

## 7. Projetos

```
Planejamento (objetivo, escopo, recursos)
  → Divisão em tarefas
    → Execução iterativa por ciclo
      → Acompanhamento (status, blockers)
        → Retrospectiva (o que aprendemos?)
          → Documentar decisões arquiteturais
```

**Temperatura:** alta no planejamento; baixa no acompanhamento  
**Etapa Focal:** Consultar (9) + Ramificar (10) + Documentar (11)

---

## 8. Sistemas Integrados

```
Modelagem de entidades e fluxos
  → Definir contratos de integração (APIs, eventos, schemas)
    → Implementar módulos
      → Sincronização entre sistemas
        → Monitoramento (healthz, logs, alertas)
          → Documentação de arquitetura
```

**Temperatura:** alta na modelagem; baixa nos contratos e monitoramento  
**Etapa Focal:** Referenciar (4) + Sintetizar (8) + Documentar (11)

---

## 9. Redes Neurais / IA

```
Coletar e preparar dados
  → Definir arquitetura do modelo
    → Treinar
      → Validar (métricas, viés, robustez)
        → Ajustar (hyperparameters, fine-tuning)
          → Implantar (deploy + monitoramento)
            → Feedback loop (dados reais → novo ciclo)
```

**Temperatura:** alta na arquitetura; baixa na validação e documentação  
**Etapa Focal:** Subverter (5) + Criar (7) + Lembrar (12)

---

## 10. Leitura

```
Leitura Mestre     → panorama geral, estrutura, tese principal
Leitura Intersemiótica → como o texto dialoga com outros textos/mídias/sistemas
Leitura Específica → mergulho nos detalhes relevantes para a tarefa
Leitura Contextual → como o texto se situa no tempo, autor, intenção
Leitura Crítica    → o que está sendo dito? o que está sendo omitido? o que subverter?
```

**Temperatura:** começa alta (Mestre) → vai baixando → sobe novamente na Crítica  
**Etapa Focal:** Compreender (2) + Referenciar (4) + Subverter (5)

## Princípio unificador

> Em todos os domínios, o Telos orienta o início.  
> A temperatura define o modo cognitivo de cada etapa.  
> O Ciclo de 12 Etapas é o motor.  
> O Conector preserva o aprendizado.
