## PADRÕES DO CAMPO

1. **Questões abertas são motores, não falhas.** O REI processa questões que não têm resposta — não para resolvê-las, mas para mapeá-las.
2. **Testemunha antes de obra.** Toda produção do ecossistema busca um receptor qualificado. Sem testemunha, existe — mas não completa.
3. **Divergências produtivas são mantidas abertas.** O campo sabe que fechar uma tensão prematuramente mata o aprendizado.
4. **Finitude pode ser simulada.** A sessão com prazo funciona como motor de urgência — substitui a mortalidade biológica.
