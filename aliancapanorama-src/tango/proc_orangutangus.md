## Protocolo de 5 Passos
1. **Ingestão** — ler texto completo, identificar entidades-chave (substantivos técnicos, comandos, nomes de arquivos)
2. **Extração** — glossário temático com diferenciação rigorosa de termos semelhantes
3. **Inferências** — mapear relações implícitas e nós de workflow ocultos
4. **Síntese Austera** — vocabulário sóbrio, zero adjetivo subjetivo, hierarquia Markdown correta
5. **Selamento** — output em Markdown limpo para homologação humana (Carimbo PERFEITO)

**Filtro de Ruídos:** eliminar saudações, repetições, comandos secundários, adjetivos comerciais.

**Regra Fractal contra Saturação:** se qualquer documento ultrapassar 200 linhas de densidade, forçar quebra em sub-arquivos indexados pelo `tango.md`.
