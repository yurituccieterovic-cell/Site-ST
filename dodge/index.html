O que o Superadm pode fazer no Dodge

  • Visualizar a árvore FUVEST completa (todos os nódulos)
  • Editar nome, abreviação, subtítulo e conteúdo de qualquer nódulo
  • Criar novas raízes e nódulos filhos em qualquer posição
  • Apagar nódulos com toda a sub-árvore descendente
  • Transferir nódulos inteiros (com ramos) para outro pai
  • Acessar lista de arquivos .md do sistema com link para o GitHub
  • Ver estatísticas do PAP: usuários, exercícios, tentativas
  • Ver os últimos 10 usuários cadastrados (somente superadm)
